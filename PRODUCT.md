# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 14+ (App Router) + Tailwind CSS. Static export target.

## Users

Creative directors, brand marketers, independent filmmakers, and content studios looking to hire a freelance video editor / motion designer for campaigns, documentaries, music videos, and brand films.

## Product Purpose

A single-page portfolio that converts visitors into clients by proving craft through curated work, clear services, and a confident contact path.

## Positioning

A cinematic, editor-owned portfolio that treats every project thumbnail like a film poster and every scroll like a scene change.

## Operating Context

- Single-page marketing site with anchor navigation.
- No backend; contact form is a presentational UI (ready to wire to a service).
- Work examples are represented by thumbnail cards (videos hosted externally, placeholders used here).

## Capabilities and Constraints

- Static Next.js build; deployable to Vercel / Netlify / any static host.
- Responsive from mobile to desktop.
- Placeholder content and external placeholder imagery; user must replace with real work.
- Supports reduced-motion via Tailwind `motion-safe:` and `prefers-reduced-motion` media query.

## Brand Commitments

- Dark cinematic visual world inspired by modern Framer portfolio templates.
- Large typography, generous negative space, and warm accent highlights.
- Placeholder persona: "Hazem" — a freelance video editor.

## Evidence on Hand

- Polished placeholder copy and synthetic project thumbnails (clearly labeled).

## Product Principles

1. Video-first hierarchy: the work is the hero.
2. Cinematic pacing: scroll feels like a timeline.
3. Confident restraint: fewer, larger elements over cluttered grids.
4. Clear action: every viewport leads toward contact or project review.
